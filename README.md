SimLab OS Trainer
SimLab OS Trainer is a safe, sandboxed computer lab for high-school IT courses. Students get hands-on practice with operating systems, hardware, networking and databases without needing administrator access on school machines. Everything happens inside the program, so nothing a student types or clicks can change the real computer.
Three pretend computers
  •  Students choose Panes 11 (Windows-style), Summit OS (macOS-style) or Pinecone Linux.
  •  Each one powers on like a real PC. The start-up screen accepts the usual keys for the BIOS/UEFI setup, the boot menu, recovery and GRUB.
  •  Each has a realistic desktop with working terminals, a file manager, settings, Task Manager, Device Manager, Network Connections, Active Directory tools and a simulated school network.
Learning built in
  •  Ticket queue: help-desk tickets in Easy, Normal or Hard mode. The tickets follow CompTIA Tech+, A+ and Network+ topics.
  •  Tutorials: each step explains what's happening "under the hood" in the hardware and software.
  •  Practice mode: flash cards, quizzes, timed practice tests with performance-based questions, and a command-speed drill.
  •  Lab reports: results can be saved for submitting to Canvas.
Hardware simulator
  •  Computer hardware: build a PC from real-world parts on a scrolling workbench. Students install the CPU, cooler, memory, drives, graphics card and power supply, run the cables, ground themselves against static, and power on to read the debug lights and beep codes. They can run game benchmarks and fix customers' broken PCs.
  •  Networking hardware: fill a network rack with switches, routers, firewalls, servers and AV gear, then run patch cables through a server room, office and conference room. Devices are configured from a laptop (VLANs, DHCP, PoE, routing). Students also crimp their own RJ45 cables and check them with a cable tester.
Code Lab
  •  An SQL playground with eight databases, including Countries, Animals, Video Games and PC Components.
  •  47 SQL challenges, pseudocode tracing puzzles, and short lessons on programming basics.
Motivation that isn't about grades
  •  Students earn stars, achievements and skill badges, with a "ghost" run to beat their own best time.
  •  The Star Shop sells themes, desktop pets, wallpapers and extra PC parts. The Arcade has mini games with hidden stars.
Accessibility
  •  Larger text, high contrast, brightness, narration with captions, a big cursor, colour-blind-safe colours, extra time and remappable keys.
  •  Menus can also be shown in Spanish.
